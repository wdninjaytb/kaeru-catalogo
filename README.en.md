# 🐸 Kaeru Produtos Orientais — Catalog

[🇧🇷 Português](README.md) | 🇺🇸 **English** | [🇯🇵 日本語](README.ja.md)

Academic project developed during the Analysis and Systems Development program at Centro Universitário Integrado.

**Kaeru Produtos Orientais** simulates the online catalog of an oriental products store, allowing users to browse products and navigate through different product categories.

## 📸 Preview

![Kaeru Produtos Orientais Catalog](catalogo-kaeru.png)

## ✨ Features

- Dynamic product display
- Product filtering by category
- Dynamically loaded categories
- Database integration
- Page navigation
- Responsive layout
- Institutional page
- Contact page

## 🛠️ Technologies

- PHP
- MySQL / MariaDB
- HTML
- CSS
- Bootstrap
- JavaScript
- PDO

## 🗂️ About the System

This repository contains the **public-facing application** of Kaeru Produtos Orientais.

The data displayed in the catalog is managed through a separate administrative panel.

## ⚙️ Local Setup

The project uses PHP and MySQL/MariaDB and can be run locally using an environment such as XAMPP.

The database connection must be configured according to the local environment before running the application.

## 🔗 Admin Panel

The project also includes a separate administrative application for system management.

➡️ [**Kaeru Produtos Orientais — Admin Panel**](https://github.com/wdninjaytb/kaeru-admin)

## 🎓 Academic Context

This project was developed as an academic assignment for the **Analysis and Systems Development** program.

Its development involved building the public interface, integrating a database and implementing dynamic features using PHP.
